# New Money Workspace

This folder is organised as a small workspace around the New Money app.

## Folders

- `App/` - the web app, iOS app, Firebase/Vercel config, source code, tests, tools, docs, and simulation outputs.
- `Brand/Logo/` - standalone brand assets.
- `.github/` - repository automation.

## Common Commands

Run app commands from `App/`:

```bash
cd App
npm run dev
npm run check
npm run build
```

Open the iOS project from:

```bash
App/ios/NewMoneyIPhone/NewMoneyIPhone.xcodeproj
```
